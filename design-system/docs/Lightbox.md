Clinical lightbox. The mandated Bodology popup style: periwinkle (#e3e7ff) box, accent border, 36px/400 centered title, 18px centered body, underlined Close link, translucent cream overlay. Controlled via `open`/`onClose`.

```tsx
<Lightbox open={open} title="The 40:1 Ratio" onClose={close}><p>...</p></Lightbox>
```
Use this style for ALL popups — do not invent other popup styles.
